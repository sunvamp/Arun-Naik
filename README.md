# Arun Naik Cybersecurity Consulting

A professional personal-brand website for a senior cybersecurity consultant specialising in GRC, cyber business analysis, and secure technology transformation.

## 🚀 Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **UI Components:** Custom components with shadcn/ui patterns
- **Icons:** Lucide React
- **Deployment:** Static Export (Vercel/Netlify ready)
